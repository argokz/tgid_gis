Запись:"Узел с заданным напором расчетной схемы тепловой сети".

Запись предназначена для отображения в информационной базе исходных данных, необходимых для определения корневого (опорного) узла, т.е. узла напоры в котором только по обратному или по подающему и обратному трубопроводам задаются пользователем и используются при расчете в качестве исходной точки для определения напоров в остальных узлах в процессе расчета потокораспределения. Кроме того, в опорный узел по умолчанию подключается поток подпитки, балансирующий частичный или полный водоразбор у потребителей расчетной схемы.
