Запись: "Коэффициенты вариации значений параметров элементов расчетной схемы".

>

Запись предназначена для предоставления пользователю широких возможностей изменения значений исходных данных, с целью вы- полнения многовариантных расчетов гидравлических режимов путем изменения (масштабирования) исходных данных для конкретного варианта расчета.
