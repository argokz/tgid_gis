Запись: "Потребители тепловой энергии".

Запись предназначена для ввода в информационную базу ис- ходных данных по потребителям тепловой энергии, необходимых для расчета гидравлического режима сети. Внимание!!! В данном документе не следует записывать данные по узлам,не содержащим присоединенной тепловой нагрузки, в том числе узлам, являющимся входными и выходными для насосных станций и регуляторов, т.к. их описание осуществляется в записи с кодом УС.
