Запись: "Байпасы расчетной схемы."

Запись предназначена для описания характеристик байпасов, используемых для расчета параметров внешних диафрагм, устанавливаемых на байпасах и предназначенных для фиксации расчетного гидравлического режима неавтоматизированных тепловых пунктов на распределительных сетях нагруженных реальными потребителями тепла с типовым набором теплопотребляющих систем. Исходная информация сосредоточенная в записи позволяет выполнить автоматическое дросселирование потока теплоносителя на участке расчетной схемы в месте установки байпаса с целью достижения заданного напора на выходе байпаса или заданного расхода через байпас .Дросселирование по напору целесообразно использовать при расчете диаметра диафрагм используемых для гашения избыточного напора на заданном участке подающего или обратного трубопроводов а дросселирование по расходу - для расчета диаметра диафрагм, устанавливаемых на перемычках между подающим и обратным трубопроводами с целью фиксации расхода теплоносителя из обратного трубопровода исходя из необходимости реализации заданного коэффициента смешения обеспечивающего требуемый температурный график.
