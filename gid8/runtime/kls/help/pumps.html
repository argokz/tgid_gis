Запись: "Hасосы (насосные станции) расчетной схемы"

Запись состоит из совокупности полей, значения которых предназначены для описания характеристик насосов или насосных станций разного назначения: установленных в водоподогревательных установках источников тепла, используемых для перекачки (транспорта) теплоносителя на подающем или обратном трубопроводах, выполняющих функции подмешивания сетевой воды из обратного трубопровода в подающий (устанавливаемых на тепловых пунктах), используемых для подпитки сети из внешних источников и, работающих, как реально в теплоснабжающей системе, так и устанавливаемых для целей имитационного моделирования гидравлических режимов.

Программной системой предусмотрена возможность выполнения работ по выбору характеристики насоса из каталога, построения и аппроксимации характеристики насосной станции с помощью программных средств специального "Сервиса технолога". и внесение результатов аппроксимации непосредственно в соответствующие поля записи "НC".
