Запись: "Участки трубопроводов расчетной схемы."

Запись предназначена для описания характеристик участков подающего и обратного теплопроводов с целью последующего определения их гидравлических сопротивлений, необходимых для расчета потокораспределения и потерь напоров на участках. Насосы, насосные станции и регуляторы в данной записи не описываются. Кроме этого, в записи описываются характеристики участка необходимые для расчета тепловых потерь этим участком.

ПРАВИЛА описания участков теплопровода следующие: Если значения полей 12 - 20 записи с кодом - УТ одинаковы для участка по подающему и обратному трубопроводам,то такой участок описывается один раз (одной записью) и в полях "Признак трубопровода" для начального и конечного узлов должны отсутствовать символы "П" или "О",вместо них должен быть "пробел". Если же для участка теплопровода характеристики подающего и обратного трубопроводов различны (разное число труб, разные диаметры труб, длины, эквивалентные шероховатости, коэффициенты местных сопротивлений или потерь, разные значения гидравлических сопротивлений, то такой участок описывается дважды, в двух следующих друг за другом записях. При этом наименования начального и конечного узлов в обеих записях одинаковы: в первой записи записываются характеристики (исходные данные) участка по подающему трубопроводу с указанием символа "П" в качестве значения полей "Признак трубопровода" для начального и конечного узлов, а во второй - аналогичная информация по обратному трубопроводу с указанием символа "О" в качестве значения полей "Признак трубопровода" для начального и конечного узлов. Участки по подающему и обратному трубопроводам с оригинальными начальными и конечными узлами описываются каждый в отдельной записи с указанием соответствующих символов в качестве значений полей "Признак трубопровода" для начального и конечного узлов.
