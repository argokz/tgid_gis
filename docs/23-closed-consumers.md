# Закрытые потребители

Сценарий переносит команду старого ТГИД `aZap6`. Термин «закрытый» здесь
означает состояние потребителя `consumerstateid = 2`, а не закрытую схему ГВС.

Список строится непосредственно по активным `net.consumer_real` и
`net.consumer_general`. Для каждой строки показываются объектный и исходный ID,
класс, фрагмент, внешний код, имя узла и имя потребителя.

## Справочник внешних кодов

Старый запрос соединял потребителя с `externalcodes` без указания схемы: до
удаления дублей имя разрешалось в `public`, после шага 124 — в `ref`. Миграция
`sql/123_externalcodes_reference.sql`:

- копирует все 698 записей и полную структуру в `ref.externalcodes`;
- создаёт собственную последовательность `ref.externalcodes_id_seq`;
- добавляет внешние ключи `externalcodeid` всех девяти узловых классов;
- переводит эти поля `meta.field_catalog` на lookup `ref.externalcodes`;
- повышает версию контракта БД до 13.

Скрипт применяется в сборочной или переходной БД, пока доступна исходная
`public.externalcodes`. Чистая сборка включает готовую таблицу `ref` в
продуктовый дамп, поэтому в рабочей БД legacy-таблица не нужна.

## Возможности Qt

- вся БД или один фрагмент;
- поиск по коду, имени узла, потребителю и исходному ID;
- до 1 000 строк с предупреждением о необходимости уточнить фильтр;
- двойной щелчок открывает карточку объекта;
- экспорт текущего результата в UTF-8 CSV.

## Проверка совместимости

`sql/tests/test_externalcodes_reference.sql` проверяет число записей
справочника, lookup-метаданные, внешние ключи и двусторонний `EXCEPT` между
старым и новым `aZap6`. На текущей БД оба запроса возвращают одинаковые 77
строк без расхождений.

```powershell
psql -f sql/123_externalcodes_reference.sql
psql -f sql/tests/test_externalcodes_reference.sql

.\tgid_app\build\Release\tgid_app.exe --closed-consumers
.\tgid_app\build\Release\tgid_app.exe `
  --closed-consumers --closed-consumer-fragment 72
.\tgid_app\build\Release\tgid_app.exe `
  --closed-consumers --closed-consumer-search Абая
```

Коды завершения CLI: `0` — успех, `42` — неверный ID фрагмента, `43` — ошибка
запроса или контракта БД.
