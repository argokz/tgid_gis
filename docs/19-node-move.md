# Атомарное перемещение узлов

Qt-клиент позволяет переместить выбранный активный узел щелчком по новому
положению на карте. Операция работает с опубликованными точечными классами
`net` и не обращается к `public.nodes`.

## Серверный контракт

Функция `net.move_node(table, id, expected_version, x, y)`:

1. проверяет безопасное имя таблицы и регистрацию ID в `net.node_reg`;
2. подтверждает редактируемый точечный слой и его SRID по каталогу;
3. блокирует строку узла и проверяет активность и `row_version`;
4. обновляет `geom` в одной транзакции;
5. возвращает новую версию и число подключённых активных линий.

Триггер `net.propagate_node_geometry` перестраивает соответствующий конец всех
линий. Если новое положение совпадает с другим концом той же линии, обычная
проверка топологии отклоняет всю транзакцию. Частично перемещённого состояния
не возникает.

Миграция также устанавливает `geometry_change_audit` на объектные таблицы.
Теперь изменение `geom` из Qt, QGIS или SQL добавляет в `changed_fields`
старую и новую огибающую и SRID. Для точки огибающая содержит её точные
координаты.

## Qt и CLI

В Qt кнопка **Переместить узел** доступна только для одного активного узла,
выбранного на текущей карте. После подтверждения карта и карточка перечитываются.
При параллельной правке показывается конфликт, чужое изменение не затирается.

```powershell
.\tgid_app\build\Release\tgid_app.exe `
  --move-node connect_node:10001:700012.5:4800007.25 `
  --expect-version 3
```

Коды CLI: `32` — неверные параметры, `33` — конфликт версии, `34` — отказ
топологии или другая ошибка перемещения.

## Проверка

Тест [test_node_move.sql](../sql/tests/test_node_move.sql) выполняется внутри
транзакции с `ROLLBACK`. Он создаёт два временных узла и участок, перемещает
первый узел и проверяет:

- точные новые координаты;
- новое начало линии;
- увеличение версий узла и линии;
- число перестроенных линий;
- отказ для устаревшей версии;
- запись изменения геометрии в аудит.

Контракт БД после миграции — версия 11.
